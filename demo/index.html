About This Demo

This lightweight interactive demo was recreated for portfolio purposes based on my primary contribution to the frontend Query Builder and dynamic Flux Query Generation functionality in a university industry project.

The User-defined Hierarchy section is included as a related team integration because it consumes the Flux query produced by the Query Builder. It is not presented as my primary individual contribution.

Mock data is used so the workflow can be demonstrated safely without exposing the original internal project environment, credentials, or university infrastructure.
